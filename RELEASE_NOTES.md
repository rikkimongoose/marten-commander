# Marten Commander 0.3.0

Третий выпуск двухпанельного файлового менеджера. Релизный артефакт предназначен
для Linux amd64.

## Новые функции

- SFTP-профили с парольной, key- и agent-аутентификацией, проверкой host key и
  стартовым remote path. Панель использует POSIX-пути, сохраняет состояние второй
  панели и восстанавливает прежний локальный каталог после отключения.
- F5 потоково скачивает обычные файлы из SFTP-панели в локальную через временный
  файл, с прогрессом, отменой и существующим разрешением конфликтов. Контекст
  источника, сессия и каталог назначения фиксируются при вызове команды.
- F3 открывает локальные и удалённые обычные файлы во встроенном read-only Viewer.
  Удалённый Viewer читает файл через зафиксированную SFTP-сессию.
- Space на локальном каталоге считает размер дерева в фоне. Пустой каталог даёт
  ноль, символические ссылки пропускаются, результат привязан к исходной строке.
- `style.yaml` из пользовательского каталога конфигурации задаёт цвета имён файлов
  по регистронезависимым glob-маскам для локальных и SFTP-панелей.
- Сохранены безопасные локальные F5/F6/F7/F8, внешний F4 и командная строка;
  удалённый источник не передаётся локальным обработчикам.

## Безопасность удаления

F8 не поддерживает безвозвратное удаление. Если GIO или корзина выбранного тома
недоступны, операция завершается ошибкой; fallback на `rm`, `os.Remove`,
`os.RemoveAll` или `gio remove` отсутствует. Символическая ссылка переносится в
корзину как ссылка, без обхода её цели.

## Известные ограничения

- Windows не проходил обязательную проверку для этого выпуска; публикуется только
  Linux amd64 артефакт.
- Безвозвратное удаление не поддерживается.
- Для F8 требуется утилита `gio`; восстановление и очистка корзины выполняются
  средствами операционной системы.
- Запись на SFTP отсутствует. Нельзя копировать local→SFTP или SFTP→SFTP,
  перемещать, создавать и удалять удалённые объекты. Скачивание каталогов и
  символических ссылок отложено.
- Подсчёт размера по Space выполняется только для локальных каталогов.
- Наблюдение за каталогами, экран настроек, установщик, AppImage, deb/rpm и
  автоматическое обновление пока отсутствуют.
- Бинарник динамически зависит от GTK4 и WebKitGTK 6.0.

Инструкция установки и smoke checklist находятся в `README.md` рядом с бинарником
в релизном архиве и в `docs/linux-release.md` в репозитории.
